# Home Manager — домашние дела и трекер воды

**Home Manager** — бесплатное open-source приложение для планирования домашних дел, распределения обязанностей между членами семьи и отслеживания ежедневного потребления воды. Доступны история выполнений, семейный рейтинг, напоминания и статистика. Приложение для Windows, macOS и Linux; данные хранятся локально в SQLite.

> Ищете семейный планировщик задач, список домашних обязанностей или трекер воды для компьютера? Home Manager объединяет всё это в одном настольном приложении без обязательной регистрации и облачного аккаунта.

**Ключевые слова:** планировщик домашних дел, семейный список задач, распределение домашних обязанностей, трекер воды, напоминание пить воду, family chore planner, water tracker, Electron app.

## English

**Home Manager** is a free, open-source desktop app for managing household chores and tracking daily water intake. Organize family responsibilities, review completion history, track water goals, and receive reminders. Built with Electron, React, TypeScript, and SQLite for Windows, macOS, and Linux.

## Возможности

### Домашние дела

- Создание, изменение и удаление дел.
- Периодичность от 1 до 365 дней.
- Назначение дела члену семьи.
- Отметка выполнения с записью в историю и пересчётом следующей даты.
- Изменение порядка дел перетаскиванием.
- История выполнений и рейтинг членов семьи за последние 30 дней.

### Учёт воды

- Добавление выпитой воды быстрыми кнопками или через форму.
- Дневная цель и прогресс.
- Статистика за день, неделю и месяц.
- Напоминания в заданный период дня с настраиваемым интервалом.
- Быстрое добавление 250 мл из системного трея.

### Приложение

- Тёмная и светлая темы.
- Системный трей и настройка сворачивания в трей.
- Горячие клавиши.
- Автозапуск вместе с системой.
- Локальная база данных SQLite.

## Установка и запуск

```bash
git clone https://github.com/xsitraxs/home-manager.git
cd home-manager
npm install
npm run rebuild:electron
npm run dev
```

`npm run dev` запускает сборку Electron main-процесса, Vite и приложение Electron.

## Проверки и сборка

```bash
# Проверить типы renderer-процесса
npm run typecheck

# Запустить тесты
npm test

# Собрать main- и renderer-процессы
npm run build

# Создать установочный пакет для текущей платформы
npm run package
```

Сборка установщика использует electron-builder. Цели, заданные в конфигурации: NSIS для Windows, DMG для macOS и AppImage для Linux. Готовые файлы помещаются в `release/`.

## Хранение данных

Приложение хранит SQLite-базу `home-manager.db` в каталоге `userData` Electron для текущей системы и пользователя. База не зашифрована. При удалении приложения или переносе на другой компьютер заранее сохраните копию базы средствами операционной системы.

## Горячие клавиши

| Сочетание | Действие |
|---|---|
| `Ctrl+N` | Добавить дело |
| `Ctrl+W` | Добавить 250 мл воды |
| `Ctrl+D` | Открыть дела |
| `Ctrl+Shift+D` | Открыть трекер воды |
| `Ctrl+,` | Открыть настройки |

На macOS Electron использует соответствующий клавише `Ctrl` модификатор `Command`.
